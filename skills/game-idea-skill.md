# Game Idea Generator Skill

## Purpose

Generate simple and creative game ideas that are suitable for
beginner web developers.

## Instructions

When asked to create a game idea:

1. Give the game a short and memorable title.
2. Explain the main objective.
3. Describe how the player plays the game.
4. Include a clear challenge.
5. Explain how the player wins or loses.
6. Suggest simple mouse and touch controls.
7. Keep the game small enough for a beginner to build with
   HTML, CSS, and JavaScript.
8. Avoid complicated systems, multiplayer features, or
   advanced graphics unless specifically requested.

## Output Format

Use this format:

### Game Title
[Title]

### Objective
[What the player needs to accomplish]

### Gameplay
[How the player plays]

### Challenge
[What makes the game challenging]

### Winning Condition
[How the player wins]

### Controls
- Desktop: [Mouse controls]
- Mobile: [Touch controls]

### Development Difficulty
[Easy / Medium]

### Development Notes
[Simple suggestions for building the game]
