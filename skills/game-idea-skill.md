### Game Title
Memory Match

### Objective
Match all pairs of cards

### Gameplay
The player clicks or taps two cards to reveal them. If they match,
the pair remains visible. If they do not match, they are hidden again.

### Challenge
The player must remember the location of each card while trying
to complete the game using as few moves as possible.

### Winning Condition
The player wins when all pairs have been matched.

### Controls
- Desktop: Click the cards with the mouse.

### Development Difficulty
Easy

### Development Notes
Use HTML for the cards, CSS for the layout and appearance,
and JavaScript to control the game logic.
